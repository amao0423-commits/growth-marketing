利用規約

制定 2026年8月20日 ／ 最終改定 2026年8月20日
この規約は雛形です。実際の運用開始前に、必ず弁護士等の専門家によるレビューを受けてください。事業内容、責任範囲、料金体系によって必要な条項は異なります。

この利用規約（以下「本規約」といいます）は、株式会社ホットセラー（以下「当社」といいます）が提供するプレスリリース掲載サービス「アドプレス」（以下「本サービス」といいます）の利用条件を定めるものです。本サービスをご利用になる方（以下「利用者」といいます）は、本規約に同意したものとみなします。

第1条（適用）

  1. 本規約は、本サービスの利用に関する当社と利用者との間のすべての関係に適用されます。
  2. 当社が本サービス上で掲載する掲載ガイドラインその他の個別規定は、本規約の一部を構成します。
  3. 本規約と個別規定の内容が異なる場合、本規約の規定が優先して適用されます。

第2条（定義）

投稿記事利用者が本サービスに投稿し、掲載された記事
紹介リンク利用者が自ら運営する媒体等において投稿記事を紹介したページ
マイページ利用者が投稿記事を管理するための本サービス上の画面

第3条（アカウント）

  1. 利用者は、当社が定める外部サービス（Google）のアカウントを用いて本サービスにログインするものとします。
  2. 利用者は、自己の責任においてアカウントを管理するものとし、第三者に利用させ、または貸与、譲渡、売買してはならないものとします。
  3. アカウントの管理不十分、使用上の過誤、第三者の使用等による損害の責任は利用者が負うものとし、当社は責任を負いません。
  4. 利用者は、マイページにおいて表示名（会社名、団体名またはニックネーム）を登録するものとします。表示名は投稿記事の発信元として公開されます。

第4条（記事の投稿）

  1. 記事の投稿は、当社が認めた編集部アカウントに限り行うことができます。
  2. 利用者は、投稿にあたり、当社が指定する事項（記事の内容、カテゴリ、発信元の名称、連絡先等）を入力するものとします。
  3. 記事内のリンクは、本文中および記事末尾の参考リンクを合算して2本以内とします。
  4. 利用者は、投稿記事について、公表する正当な権限を有していることを保証するものとします。
  5. 本サービスの利用に必要な通信機器、ソフトウェア、通信環境等は、利用者の費用と責任において用意するものとします。

第5条（掲載内容の責任）

  1. 投稿記事の内容についての責任は、すべて当該記事を投稿した利用者に帰属します。
  2. 当社は、投稿記事の内容の真実性、正確性、適法性、有用性について、いかなる保証も行いません。
  3. 利用者は、投稿記事が第三者の権利を侵害しないこと、および法令に違反しないことを保証するものとします。
  4. 投稿記事に関して利用者と第三者との間に紛争が生じた場合、利用者は自己の費用と責任においてこれを解決するものとし、当社に一切の迷惑をかけないものとします。当社が損害を被った場合、利用者はこれを賠償するものとします。

第6条（禁止事項）

利用者は、本サービスの利用にあたり、次の行為をしてはなりません。

  1. 法令または公序良俗に違反する行為
  2. 犯罪行為に関連する行為
  3. 次の内容を含む記事を投稿する行為
    1. 性的な表現、暴力的な表現、自傷を助長する内容
    2. 特定の個人または団体に対する誹謗中傷、差別的な表現
    3. 元本保証をうたう投資勧誘、連鎖販売取引、情報商材の販売に関する内容
    4. ギャンブル、アダルトサービス、出会い系サービスに関する内容
    5. 医薬品医療機器等法、景品表示法その他の法令に違反するおそれのある表示
    6. 同意のない第三者の個人情報
  4. 第三者になりすまして記事を投稿する行為、または権限なく他者の発表を投稿する行為
  5. 第三者の著作物を無断で転載する行為
  6. 同一または類似の内容の記事を繰り返し投稿する行為
  7. アフィリエイトリンクその他、記事の内容と関連しないリンクを設置する行為
  8. 検索エンジンの評価操作のみを目的として本サービスを利用する行為
  9. 本サービスの運営を妨害する行為、または不正アクセスその他の技術的手段により本サービスに影響を与える行為
  10. その他、当社が不適切と判断する行為

第7条（審査および掲載）

  1. 投稿記事は、当社が定める方法による審査を経て掲載されます。審査には、人工知能を用いた自動判定を含みます。
  2. 当社は、審査の結果、投稿記事の掲載を拒否し、または修正を求めることがあります。
  3. 審査の判定基準の詳細については、不正な投稿を防止する目的から開示しません。
  4. 審査は、投稿記事の内容が法令に適合していることを保証するものではありません。審査を通過した場合であっても、第5条に定める利用者の責任は免除されません。
  5. 当社は、掲載の時期および掲載順序について保証しません。

第8条（掲載記事の紹介）

  1. 当社が必要と判断した場合、掲載記事の発信元に対し、自らが運営するウェブサイト、SNSアカウントその他の媒体における記事の紹介をお願いすることがあります。
  2. 当社が紹介リンクの提出を求めた場合、利用者は、紹介したページのURLをマイページを通じて当社に提出するものとします。
  3. 前項の紹介について、当社は、検索エンジンの評価を移転する形式のリンク（いわゆるdofollowリンク）の設置を求めません。SNSの投稿等、通常リンク評価を移転しない形式による紹介で足りるものとします。
  4. 前項の提出がない場合、当社は第9条第3項にもとづき投稿記事を取り下げることがあります。ただし、利用者から相当の理由の申し出があった場合、当社は期限の延長に応じることがあります。

本条は、投稿記事が読者に届くための告知への協力をお願いするものであり、検索エンジンの評価を目的としたリンクの提供を義務づけるものではありません。

第9条（編集および取り下げ）

  1. 利用者は、掲載日から1ヶ月間に限り、投稿記事の本文およびアイキャッチ画像を編集することができます。編集後の記事は、あらためて第7条の審査の対象となります。
  2. 利用者は、マイページを通じて、いつでも投稿記事を取り下げることができます。
  3. 当社は、次のいずれかに該当する場合、事前の通知なく投稿記事を取り下げ、または非公開とすることができます。
    1. 第8条第2項に定める提出が期限までにない場合
    2. 本規約または掲載ガイドラインに違反することが判明した場合
    3. 第三者から権利侵害の申し立てを受け、相当と認められる場合
    4. 掲載内容に事実と異なる記載があることが判明した場合
    5. 法令、行政機関の指導または裁判所の命令にもとづく場合
    6. その他、当社が掲載の継続を不適当と判断した場合
  4. 当社は、前項による措置について、利用者に生じた損害の責任を負いません。
  5. 当社は、利用者が本規約に違反した場合、当該利用者のアカウントの利用を停止し、または本サービスの利用をお断りすることができます。

第10条（知的財産権）

  1. 投稿記事に関する著作権その他の知的財産権は、当該記事を投稿した利用者または正当な権利者に帰属します。
  2. 利用者は、当社に対し、投稿記事を本サービスおよび当社が運営する媒体において掲載、複製、公衆送信、翻案（体裁の調整、要約の作成、アイキャッチ画像の生成を含む）するために必要な範囲で、無償かつ非独占的に利用することを許諾するものとします。
  3. 前項の許諾は、投稿記事が取り下げられた後も、検索エンジンのキャッシュその他当社の管理が及ばない範囲において存続することがあります。
  4. 本サービス自体に関する知的財産権は、当社または当社にライセンスを許諾している者に帰属します。

第11条（個人情報）

  1. 当社は、本サービスの利用により取得した個人情報を、プライバシーポリシーに従って適切に取り扱います。
  2. 利用者が投稿記事において公開を選択した連絡先（メールアドレス、電話番号、ウェブサイトURL）は、記事とともに公開されます。
  3. 当社から利用者への連絡は、原則としてマイページのお知らせ機能により行います。重要な連絡がある場合に限り、登録されたメールアドレスへ通知を送信することがあります。

第12条（免責事項）

  1. 当社は、本サービスに事実上または法律上の瑕疵（安全性、信頼性、正確性、完全性、有効性、特定の目的への適合性、セキュリティに関する欠陥、エラーやバグ、権利侵害を含みます）がないことを保証しません。
  2. 当社は、投稿記事の閲覧数、反響、その他の効果について、いかなる保証も行いません。掲載レポートに表示する数値は集計上の目安です。
  3. 当社は、本サービスに関して利用者が被った損害について、当社に故意または重過失がある場合を除き、責任を負いません。
  4. 前項にかかわらず、当社が責任を負う場合であっても、賠償の範囲は、当該損害が生じた時点から遡って1年間に利用者が当社に支払った金額を上限とします。当社に支払った金額がない場合、この上限は0円とします。
  5. 当社は、利用者と第三者との間に生じた紛争について、責任を負いません。

第13条（サービスの変更・中断・終了）

  1. 当社は、利用者への事前の通知なく、本サービスの内容を変更し、または提供を中断することができます。
  2. 当社は、本サービスの提供を終了する場合、可能な範囲で事前に本サービス上において告知します。
  3. 当社は、本条にもとづく措置により利用者に生じた損害の責任を負いません。

第14条（規約の変更）

  1. 当社は、必要と判断した場合、本規約を変更することができます。
  2. 本規約の変更が利用者の一般の利益に適合する場合、または変更が契約の目的に反せず、必要性、変更後の内容の相当性その他の事情に照らして合理的である場合、当社は本サービス上での告知により本規約を変更することができます。
  3. 前項の場合、当社は変更後の本規約の内容および効力発生時期を、効力発生時期の相当期間前までに本サービス上に掲示します。

第15条（準拠法・管轄）

  1. 本規約の解釈にあたっては、日本法を準拠法とします。
  2. 本サービスに関して紛争が生じた場合、当社の本店所在地を管轄する裁判所を第一審の専属的合意管轄裁判所とします。
